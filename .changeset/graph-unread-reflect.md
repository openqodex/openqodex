A caller list is now a floor when a call to the function may hide in code the graph could not read. Two places that gave up in silence now say so. A syntax error, or any region the parser could not read, in any of the seven languages, is a gap. It names every word written there and just around it. A method found by a name given at run time is a gap too: Java `getMethod` and `getDeclaredMethod`, Go `MethodByName` and Python `getattr`. A name written as a plain string is a call of that name; any other name may reach any function of the project. The floor's reason now says which of the two it is, in place of "1 call named `x` could not be bound". A string shaped like a key, given as a name or left unterminated near a syntax error, is never kept in the graph's cached facts; Ruby `send("...")` follows the same rule. Kept indexes are built again once.
