Four fixes to query answers. `graph tests` no longer lists every name-based lead beside its test links: the leads are one page long, and the answer says how many more there are and that `graph callers` lists them. `--compact` now also compacts the `handles` of a route. `--context` now gives lines for the site in an explained framework edge and for each handler site of a route. A source line holding a key written with percent-encoding (`ghp%5F...`) is now replaced whole in `--context` lines.
