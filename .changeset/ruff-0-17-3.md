The bundled ruff Python linter moves to 0.17.3, so repositories whose ruff config names newer rules such as `UP046` are linted instead of failing the scanner. This ruff reads `requires-python` from a `pyproject.toml` with no `[tool.ruff]` table as its target version, so a change to it there now raises the ruff settings note. ruff's default rule set grew from 59 rules to 407, so a repository with no ruff `select` now gets more findings, including the security rules S102, S110 and S112, which OpenQodex ranks as high severity. To keep the old set, add `select = ["E4", "E7", "E9", "F"]` to the repository's ruff config.
