The bundled ruff Python linter moves to 0.17.3, so repositories whose ruff config names newer rules such as `UP046` are linted instead of failing the scanner. This ruff reads `requires-python` from a `pyproject.toml` with no `[tool.ruff]` table as its target version, so a change to it there now raises the ruff settings note.
