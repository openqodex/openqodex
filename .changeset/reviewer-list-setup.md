`init` in your own terminal now shows the reviewer list it plans for the team and asks before writing it: keep it, change the order, leave reviewers out, or write no list. From an agent or with `--yes`, `init` writes the planned list without asking, as before. A review in a project with no reviewer list now names the reviewer the automatic order picked, in the receipt and the report, and says to run `openqodex init` to pin the reviewers for the whole team.
