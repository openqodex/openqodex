---
"openqodex": minor
---

`openqodex graph packages` now counts every line that imports a project. A file that imports one package twice, such as `import type { Turn }` and `import { TurnSchema }` from the same module, or an import and an `export ... from`, kept only its first line, so on TrueForge 8 of the 240 imports of `@truefoundry/trueforge-core` were missing. Each line is now its own import site. `importers` still lists each importing file once.

A call through a TypeScript interface now also reaches the classes that match the interface by shape. TypeScript accepts a class wherever an interface is asked for when it has the interface's members, even without `implements`, so a class that has every method by name (methods marked `?` aside) is listed as a possible target, with evidence `by-shape`. At most 20 classes are kept per call; a class past them that runs a method not listed leaves a `fan-out-capped` gap that marks the list as incomplete. Such a call no longer leaves an `unsupported-rule` gap when every value that may answer it is listed: on TrueForge these gaps fell from 974 to 719, and on `ISessionStore` from 56 to 20. The gap stays when the interface extends a type from a package, when a class that has the method extends a class from a package, and when an object literal written in place (an argument, an object a function returns) has the interface's methods or spreads another object, since its code is no definition of the graph.

A TypeScript method called on what a package returned is now external, at any depth of a chain, instead of an unknown that set the floor of every repository method of the same name. `db.selectFrom("t").where(...).execute()` and `z.string().min(1).optional()` were gaps past the first call; on TrueForge the production TypeScript calls with no receiver type fell from 6,574 to 5,717 (`where` 477 to 245, `execute` 274 to 193). Such a call stays a gap when the repository subclasses or implements a package's type with a method of that name, or adds it with `declare module`, because the value may be the repository's own object. Before, a call on a package's result was external even then.
