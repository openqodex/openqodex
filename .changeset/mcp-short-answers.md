Code graph answers over MCP are now short by default. Each item carries a short edge id that `graph_explain` takes, and leaves out what it repeats: the column, the rule, the import line, the end that is the target, the end that is the file of the site, and a floor example an item already shows. A 10-caller answer on a large TypeScript repository went from 13,047 characters to 4,419. Pass `full: true` for the answer `openqodex graph --json` prints. Long edge ids still explain. `search` now puts definitions whose name is the text, or starts with it, in `items` (an exact name likely, a prefix possible: a name match alone is never certain); other hits stay in `leads`. `implementers IMCPServer` finds the file `IMCPServer.ts` when no symbol has that name, and lists the classes and interfaces it defines.
