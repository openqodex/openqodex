A FastAPI application with dependencies at every level: `FastAPI(dependencies=[Depends(audit)])`, `APIRouter(prefix="/items", dependencies=[Depends(auth_user)])`, a handler parameter `db=Depends(get_db)` beside a `Query(None)` default, an `Annotated[str, Depends(get_current_user)]` parameter, and `Security(get_current_user)`. `get_current_user` itself takes `db=Depends(get_db)`. A second application in app/other.py calls a `Depends` of its own from app/shim.py, and `unused_helper` in app/deps.py declares `Depends(get_db)` but no route uses it. The change edits every dependency. No route calls a dependency by name, so a graph that follows only named calls finds no caller of `get_db` and says nothing is missing; an agent then takes it for unused. Each dependency must be a certain call from each route it runs for, at the `Depends` or `Security` call that declares it, and `get_db` a certain call from `get_current_user`. The lookalike `Depends` of app/other.py and the unused helper make no call of `get_db`.
