The base declares no dependency, so the controller in src/ping.ts is no route there: a dependency enables the Nest rules. The change only adds `@nestjs/common` and `@nestjs/core` to package.json; the source files are unchanged, so their facts come from the cache. A plugin whose output was cached with the file, or that decided from the manifest when it read the file, would still report nothing. The case checks that the route and its handler appear once the manifest declares Nest, with no edit to the files that hold them.
