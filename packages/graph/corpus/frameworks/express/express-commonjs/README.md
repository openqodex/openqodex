A small Express API written with CommonJS. `src/app.js` mounts one router taken with `const users = require('./users')` under `/users` and another written inline, `app.use('/items', require('./items'))`, under `/items`. Both routers end in `module.exports = router`. A graph that reads only ES imports would list `GET /:id` twice, unmounted, with nothing to say the mounts were lost. The case checks that each route keeps its full pattern under its mount prefix and is marked mounted, and that the change to `getUser` leaves the route in place.
