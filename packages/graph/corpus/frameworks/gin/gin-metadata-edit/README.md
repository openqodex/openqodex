The base's go.mod declares the module `example.com/wrong`, while main.go imports its handlers as `example.com/shop/handlers`, so the import names no package of the repository and `handlers.Ping` is a handler with status missing. The change only fixes the module path in go.mod; main.go and the handler are unchanged, so their facts come from the cache. A plugin whose output was cached with the file, or that decided what an import names when the file was read, would still report the handler as missing. The case checks that once go.mod is fixed `GET /ping` is bound to `Ping`.
