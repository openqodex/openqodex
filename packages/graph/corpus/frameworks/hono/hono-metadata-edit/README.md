The base declares no dependency, so `app.get("/ping", ping)` and `api.openapi(pingRoute, ping)` in src/server.ts are no routes there: a dependency enables the Hono rules. The change only adds `hono` and `@hono/zod-openapi` to package.json; src/server.ts is unchanged, so its facts come from the cache. A plugin whose output was cached with the file, or that decided from the manifest when it read the file, would still report nothing. The case checks that the routes, the mount, the middleware and the handlers appear once the manifest declares Hono, with no edit to the file that holds them.
