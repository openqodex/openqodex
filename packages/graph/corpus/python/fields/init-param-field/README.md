`Service.__init__(self, store: Store, wrapper: Wrapper, raw, mixed: Store)` keeps each parameter on `self`, and `Wrapper.__init__(self, *, http: Http)` keeps its `http` the same way. `Service.run` then calls `self.store.get`, `self.wrapper.http.send`, `self.raw.get`, `self.mixed.get` and `self.made.get`. The change edits `Store.get`, `Cache.get` and `Http.send`. A graph that types a field only from a constructor call finds no caller of `Store.get` or `Http.send` and says nothing is missing. A field takes the annotated type of the parameter it is given, and a chain is followed one field at a time, so `self.store.get` is a certain call of `Store.get` and `self.wrapper.http.send` a certain call of `Http.send`. `raw` has no annotation, so `self.raw.get` binds to nothing. `mixed` is given a `Store` in `__init__` and a `Cache()` in `swap`, so `self.mixed.get` is certain to neither. `self.made = Cache()` stays a certain call of `Cache.get`.
