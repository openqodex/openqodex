Shape declares `double area()` and a default method describe that calls `area()`. Circle implements Shape, defines area and does not override describe. Main calls `s.describe()` on a Shape parameter and `c.describe()` on a Circle. The change edits Circle.area. A graph that treats every interface method as abstract never binds describe; one that does not walk into the interface loses `c.describe()`; one that binds `area()` only to the abstract member hides that describe runs Circle.area. Both describe calls must bind certain to Shape.describe, and `area()` must bind certain to Shape.area and reach Circle.area as a possible dispatches_to caller.
