App holds a field of `com.vendor.Service`, a declared dependency, and calls `service.client().send("x")`. What client returns is declared outside the repository. Mailer, in App's own package, defines send. The change edits Mailer.send. A graph that matches a method by its name binds the call to Mailer.send and shows a caller that may not exist. The call must stay unbound with a no-receiver-type unknown, and Mailer.send's empty caller list must be a floor, because an unbound call shares its name.
