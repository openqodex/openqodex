Widget declares `Widget(int size)`, whose body calls `this.init()`. Plain declares no constructor. Maker calls `new Widget(3)` and `new Plain()`. The change edits the constructor and init. A graph that runs a constructor's body on the class side binds `this.init()` to nothing and loses init's caller; one that looks for a constructor Plain does not declare reports a miss for code that compiles. `this.init()` must bind certain to Widget.init, the constructor must have `new Widget(3)` as a certain caller, and `new Plain()` must be a use of the type Plain with no unknown.
