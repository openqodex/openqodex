Outer declares a static nested class Inner with a static run. Outer.local calls `Inner.run()`, and Other, in the same package, calls `Outer.Inner.run()`. Package m has a top-level class also named Inner. The change edits Outer.Inner.run. A graph that keys classes by their simple name merges the two Inner classes, and one that does not follow a class name into its nested classes loses the call from Other. Both calls must bind certain to Outer.Inner.run and never to m's Inner.
