Pattern types follow supported condition paths in if and while statements.
Negation changes which branch receives a pattern type.
A conjunction passes a pattern only when its incoming polarity is positive.
Other condition operators and method arguments do not introduce pattern bindings.
A negated while condition keeps its pattern only when no break can target that loop.
Branch frames preserve method references when the alternative is read later.
The host fields use Baz, so an incorrect Bar.go edge cannot match a field call.
The continue control has a reachable exit.
All fixtures use valid Java syntax and scope.
Surviving pattern types belong only to the statement's containing block.
A break to the guard's own label prevents its pattern type from surviving.
