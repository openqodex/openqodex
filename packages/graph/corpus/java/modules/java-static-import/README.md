App has `import static a.b.Util.helper;` and calls `helper(3)` with no receiver. Other, in App's own package, also has a static helper. The change edits Util.helper. A graph that keeps only the class of a static import loses the member and finds no caller; one that binds a bare name by the package binds it to Other.helper. The call must bind certain to Util.helper through the import and never reach Other.helper.
