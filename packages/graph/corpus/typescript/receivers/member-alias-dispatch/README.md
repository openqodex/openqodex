`const store = this.deps.store; store.get()` with `store: Store`, an interface two classes implement. The local holds whatever the member holds, which may be any class that implements Store, so the call is a certain call to Store.get and a possible call to MemStore.get and DiskStore.get, as `this.deps.store.get()` is. A copy once marked as not declared read as a value a constructor made, an exact class, and the possible calls to the implementers were lost. The same holds for a copy from a parameter's member and for a name destructured from an object type written in place (`obj: { store: Store }`). A copy assigned again (`store = other`) has no type: no certain call and no implementer.
