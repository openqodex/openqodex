`const handle = this.deps.handle; handle.createTurn()`: a const local copied from a member, then a method called on it. Since the graph made a member typed by a named type a definition (in case that type is a function type), the copy read as a local given that definition, so the call on it became a possible may_invoke edge into Deps.handle, the real call to SessionHandle.createTurn was dropped, and no unknown was left to say so. A member whose type is a class is no function: the local takes the member's type, and the call binds certain to SessionHandle.createTurn, as the destructured control does. The same holds for a class field (`this.own`) and through optional chaining. A local assigned again may hold Other, so it never binds certain. A member typed by a function type (`run: TurnFn`) keeps its possible may_invoke edge, called directly or through `.call`.
