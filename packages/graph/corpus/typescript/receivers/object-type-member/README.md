A path through a member of an object type: one aliased (type AliasDeps = { sessions: Sessions }), one written in place on a parameter, one nested in place, and one side of an intersection. The graph read an object type as untyped, so every such call was a gap. Each path must bind certain to Sessions.close. A method called on the object type itself (deps.close(), input.close()) stays an untyped-receiver gap: a value of that shape may be anything. A member both sides of an intersection declare stays unknown, and a method only one named side declares binds to it.
