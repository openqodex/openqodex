ISessionStore is an exported interface, re-exported by a barrel and imported with `import type`. deps names it as the type of an interface property, input inside a union of intersections in a type alias, and registry as a generic argument of `new Map`. The change edits its method. None of these sites is in a function signature, so a graph that reads type names only from annotations of functions, variables and fields finds no use, while every one of them may stop compiling. Each must be a certain uses_type reference at the line that names it: from the interface or type alias that holds it, or from the enclosing function.

Two controls. other/store.ts declares another interface of the same name, which other/deps.ts imports: that property must never reach src/store.ts. And `Shadow<ISessionStore>` declares a type parameter of the same name, so its member names the parameter, not the import.
