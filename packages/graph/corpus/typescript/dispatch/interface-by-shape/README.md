`load` calls `get` through a parameter typed by the interface `Store`. `DbStore` declares `implements Store`. `MemStore` declares nothing but has every member of `Store` by name (`close` is optional, so it is not needed), and TypeScript accepts a `MemStore` wherever a `Store` is asked for. `Half` has `get` but not `put`, so it can never be a `Store`. The change edits `MemStore.get`. A graph that lists only the classes that write `implements` tells the reviewer `MemStore.get` has no caller. The call must bind certain to `Store.get`, reach `DbStore.get` as before, reach `MemStore.get` as a possible caller whose note says it matches by shape, with a dispatch record of its own, never reach `Half.get`, and leave no `unsupported-rule` gap: every class that could answer the call is listed.
