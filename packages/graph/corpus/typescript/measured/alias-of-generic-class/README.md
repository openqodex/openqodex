AnyBox is a type alias of Box<unknown>. User keeps a field of type AnyBox and calls this.box.open(). The resolver follows an alias of a named type to that type, so the call binds certain to Box.open and leaves no unknown. Before the fix the lookup stopped at the alias definition, which has no members, and left a no-receiver-type miss (`AnyBox is an interface or a type alias without that member`). Trueforge: `type HarnessSandbox = Sandbox<any>` and `type TrueFoundryMcpApiClient = Pick<...>` caused 13 of the 17 production `this.field` misses.
