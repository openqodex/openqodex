AnyBox is a type alias of Box<unknown>. User keeps a field of type AnyBox and calls this.box.open(). The extractor keeps the alias as the bare name Box, but the resolver never follows a type alias to what it stands for: the lookup lands on the alias definition, which has no members, and onClass returns a no-receiver-type miss with the note `AnyBox is an interface or a type alias without that member`. Trueforge: `type HarnessSandbox = Sandbox<any>` and `type TrueFoundryMcpApiClient = Pick<...>` cause 13 of the 17 production `this.field` misses.
