createStore returns new Store() with no annotation; setup returns { store: new Store() }. A function with no declared result has the result its body provably returns, so the call on createStore() and the call on the store destructured from setup() bind certain to Store.get, with the evidence receiver-inferred. A method's inferred result is likely, since a subclass may override it. Before the fix only a return annotation gave a result type (`what createStore returns is not known to the graph`). Trueforge tests: 761 sites (createStore, getStore, getScheduleStore and other fixtures), 23 in production.
