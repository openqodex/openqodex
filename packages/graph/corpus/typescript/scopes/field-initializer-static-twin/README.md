Sandbox has an instance method and a static method, both named handleExec. The instance field tools is initialised with an arrow that calls this.handleExec(input): it runs on the instance, so it calls the instance method. The static field presets does the same, and there `this` is the class, so it calls the static method. A graph that reads every field initializer as static binds the instance field's call certain to the static method, a wrong edge (trueforge's Sandbox.ts:236 shape). A graph that reads every field initializer as an instance binds the static field's call to the instance method. Each call must bind certain to its own side and never to the other.
